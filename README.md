
# A template repo for building TypeScript-based libraries for npm, jsr.io, etc.

## Get Started

1. Fill out following fields in `package.json`:
    - `name`
    - `description`
    - `homepage`
    - `bugs.url`
    - `repository.url`
    - `license` (default is MIT License)
    - `author`
2. Install packages with package manager of your choice:
    - **npm**: `npm install`
    - **pnpm**: `pnpm install`
    - **yarn**: `yarn install`
3. Write your code
    Open `src/`, where you'll find an `index.ts` file.
    Start coding there or write your code in modules and export
    them in `index.ts`
4. Publish!
    Just run `npm publish`! (If you haven't logged in, run `npm login` first)
